## 四、三种来源导入（P0）

各来源都应检查“选择项目 → 上传与检查 → 预览 → 确认归档 → 抽取 → 审核”的状态，并记录批次 ID、错误码和服务端日志，不记录原始私人对话或令牌。

| 数据 | 操作与通过标准 |
|---|---|
| 通用 Markdown/TXT | [ ] 上传小样本、查看预览并归档；抽取后可以审核、确认并在记忆库找到。普通无角色文本目前按用户消息处理。 |
| DeepSeek Harness v4 | [ ] 分别使用 `session.v4.jsonl` 和仅包含该文件的 ZIP；确认预览的消息与工具轨迹合理，归档原文件，候选抽取成功，原对话可定位。抽取输入应排除思考和工具事件。 |
| DeepSeek 网页导出 | [ ] 导入包含 `user.json` 和 `conversations.json` 的 ZIP；检查预览的会话与消息数量、思考和附件处理，以及无法确定当前分支时的提示。审核候选并导出 Memory Pack。 |
| ChatGPT | [ ] 导入包含 `conversations.json` 的账户导出 ZIP；核对当前分支、非当前分支和不记忆标记的处理；抽取、审核并检查来源。若样本确有附件，再测试附件审核和批准进入 Knowledge。 |
| Claude | [ ] 将同一次导出的多个 ZIP 一次选齐并导入；可用 Manifest 核对完整性。检查任务、预览、归档、会话候选、平台已保存记忆的单独审核和项目文档列表。 |
| Claude 恢复 | [ ] 测试任务刷新/恢复；如使用 Manifest 下载，测试不可访问链接及按原文件名补交。多个来源项目映射到同一目标项目时检查确认提示。 |
| 异常与重复 | [ ] 测试格式错误、空文件、错误来源、损坏或超限 ZIP；应提示错误而不产生伪造的成功数据。重复导入检查去重和冲突提示，已归档内容仍可访问。 |

## 五、候选、记忆、证据及导出（P0）

- [ ] 候选审核：筛选情节、画像；检查中文输出及内容是否有意义，检查画像依据用户内容；编辑、确认、拒绝各执行一次。
- [ ] 来源证据：打开不同候选的来源，检查消息、片段及定位与导入原文一致；同一会话多条证据应定位到对应消息。人工新增显示人工来源，不伪造对话证据。
- [ ] 人工新增：分别新增情节和画像，设置项目、有效期和对外策略，审核确认；在记忆库和 Memory Pack 按类型找到它们。
- [ ] 正式记忆库：搜索、筛选、打开详情、修正、撤销和删除测试记录；复查状态与来源。使用专门测试数据，避免删除真实记忆。
- [ ] Memory Pack：分别预览并导出 Markdown、JSON；检查项目和类型范围、中文、预算及来源设置。`deny` 不进入结果，`ask` 需逐条确认；候选未确认前不进入 Pack。
- [ ] 快照变化：预览后修改或撤销已选记忆，再尝试导出；应提示重新预览或拒绝旧快照，不能静默交付过期内容。
- [ ] Knowledge：确认 embedding、rerank 与适合文件格式的解析能力已配置。批准 Claude 项目文档或 ChatGPT 可定位附件进入 Knowledge，检查状态和内容；仅归档的文件不应出现在 Knowledge 导出中。
- [ ] Knowledge 导出：按项目和筛选条件查找已入库文档，下载单个原件和所选 ZIP；核对文件名、内容及可选摘要/Topic。投递结果不确定时先核对，避免盲目重复提交。

## 六、授权与网关（P0，计划开放外部访问时）

- [ ] 网关暂停：暂停时外部凭据不能获取能力或数据；恢复后在授权范围内可用。
- [ ] 动态授权：设置项目、类型、操作、期限；令牌仅展示一次。授权范围内的 `allow` 正式记忆可读取；`ask`、`deny`、其他项目及过期/撤销记忆不可读取，日后符合条件的新记忆会进入动态范围。
- [ ] 限权和生命周期：无凭据、错误凭据、过期、撤销和轮换后的旧凭据均被拒绝；不能扩大到未授权项目或操作。查看审计结果，确认无正文和令牌。
- [ ] 固定 Pack：在导出中心选择内容并逐条确认 `ask`，创建授权并完成一次交付；重复交付被拒绝。修改已选记忆或策略后，旧包不能继续交付。
- [ ] HTTP 接口：分别验证能力查询、搜索、读取、上下文构建及获批的证据权限；检查搜索按当前实现是关键词匹配。未授权时不能读取完整原对话。
- [ ] MCP：在实际客户端安装适配器依赖、配置网关和外部令牌，检查进程启动、工具发现、一次获准调用及撤销后的拒绝。页面的 HTTP 连接测试不能代替此项。
