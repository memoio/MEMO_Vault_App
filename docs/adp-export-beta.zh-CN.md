# ADP 导出 Beta

导出从已归档的 DeepSeek Harness v4 和 Claude 会话中选择包含真实工具调用的完整会话，每个会话生成一行论文版 ADP 或 ATIF-v1.7 JSONL。多个主题处于同一会话时不会自动切分或分类。无工具调用的会话不可导出。

在「ADP / ATIF 导出 Beta」中选择轨迹，可逐条或批量设置训练授权；授权默认关闭，论文版 ADP 写入 `details.training_consent`，ATIF 写入 `extra.training_consent`，不代表训练已经发生。选择预览格式，执行对应 Schema 校验并检查脱敏预览，再使用对应的下载按钮。切换格式需要重新校验；下载前会重新生成并校验内容，来源或授权变化后需要重新校验。

DeepSeek 从 Vault 归档的原始 Harness 文件转换，检查内嵌调用与独立事件、调用结果和事件顺序。Claude 从归档原始会话按消息块顺序转换，并核对 UMIF 中的调用 ID。Claude 的思考块、未转换块和来源元数据保存在 `details.source_conversation` 中，工具结果当前支持字符串、文本块和包含文本的 knowledge 块；不支持的工具结果类型、未配对调用、缺失原件或哈希不一致会阻止该轨迹导出。

转换器和 Schema 均在 EverOS 项目中，分别为本项目维护的论文版 ADP 与 ATIF-v1.7 文本输出子集，不是官方完整验证器。Claude 按工具调用和结果分组为 ATIF 步骤，无法保持关联时会拒绝导出，不推测缺失数据。导出只生成候选数据，不执行工具或训练。脱敏规则遍历输出的正文和元数据，但无法保证识别全部敏感信息，尤其是他人信息；分享或用于训练前应检查完整预览。
